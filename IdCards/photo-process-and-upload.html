ID Card Photo Pipeline

Browser version of photo-process-and-upload.py — resize to 600×800, upload to GitHub, update SchoolVertex photos, export student IDs.

Opened as a local file — the browser uses a unique/null origin, so GitHub and API calls fail with a security/CORS error. Serve this folder over HTTP, then open from localhost:

python3 -m http.server 8765
then open http://localhost:8765/photo-process-and-upload.html
